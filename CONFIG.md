- Python 3.11+
- Groq AI (Llama 3.3 70B)
- FHIR R4
- Gradio
- FastMCP
- LangGraph

## Installation
```bash
pip install -r requirements.txt
python app.py
```

## Environment Variables
```
GROQ_API_KEY=your_api_key_here
```

## Quick Start
1. Clone repository
2. Install dependencies
3. Set GROQ_API_KEY (optional)
4. Run application
5. Access at http://localhost:7860
